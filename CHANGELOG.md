# Changelog

All notable project changes will be recorded here. Lootwright is currently
pre-alpha and has not published a tagged release.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and versioned releases will use semantic versioning when release policy is
established.

## [Unreleased]

### Added

- Laravel 13 modular-monolith, Inertia/Vue/TypeScript, PostgreSQL, local
  Redis/Horizon, CI, security, policy, and deployment foundations.
- Framework-independent domain/application contracts and PoE1/PoE2 isolation.
- Bounded format-only PoB1 import and beta PoB2 structural reader.
- Deny-by-default Policy and Provenance Gate, persistence workflow, optional-AI
  containment, reproducible fixture evaluations, and responsive fixture UI.
- Laravel Cloud pre-alpha staging decision and public repository documentation.

### Security

- Hostile-input bounds, XXE/DTD/network denial, authorization/rate-limit tests,
  secret redaction, emergency switches, encrypted retained data, and deletion
  workflows.

### Known limitations

- No approved production game ruleset or authoritative deterministic analyzer.
- No real production findings, upgrades, or Manual Trade Recipes.
- Production analysis pages remain fixture-backed.
- No public authentication flow or public production service.
- Cloud queued-artifact workflows require reviewed durable object storage.
