# Sponsorship Evaluation Milestone Plan

Status: proposed work plan. Dates begin only after an explicit written award or
credit grant; no such award currently exists.

## Milestone 0: permission and measurement baseline

- Confirm the exact program, benefit, permitted API use, amount, expiry,
  reporting duties, taxes, and attribution in writing.
- Record the evidence without describing it as endorsement.
- Reconfirm GGG policy, privacy disclosures, OpenAI data controls, model price,
  project hard limit, and the local monthly breaker.
- Publish versioned synthetic eval fixtures and baseline AI-off results.

Exit: written scope is recorded, or the milestone closes with AI and funding
remaining disabled.

## Milestone 1: bounded bilingual intent pilot

- Run deterministic parsing first.
- Evaluate opt-in English and Turkish intent extraction only on synthetic or
  expressly consented, minimized inputs.
- Measure schema validity, clarification quality, unknown-reference rejection,
  injection resistance, latency, and tokens.

Exit: zero accepted unknown IDs and zero deterministic recommendation changes.

## Milestone 2: constrained explanation pilot

- Explain only already-determined findings and recommendations.
- Validate bilingual fidelity, limitations, source/ruleset display, and AI
  labelling.
- Compare AI language with deterministic local templates and record when a call
  provides no material accessibility benefit.

Exit: snapshot integrity remains exact and graceful fallback meets the same
core workflow.

## Milestone 3: public reproducibility report

- Publish aggregate eval results, fixture and prompt-template versions, token
  distribution, spend, failures, mitigations, and known limitations.
- Publish no player prompts, private notes, credentials, or personal data.
- Decide whether continued AI use is proportionate. Disable it if benefit does
  not justify cost or privacy exposure.

## Stop conditions

Any policy denial, data leak, material prompt-injection escape, unexplained
recommendation diff, budget breach, expired credit, or unclear program term
stops AI execution. Milestones do not create an entitlement to later support.
