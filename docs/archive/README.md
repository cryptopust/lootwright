# Archived documentation

Historical plans and ADRs remain available for provenance but are not current
runtime guidance. In particular, self-hosted Docker/Redis/Horizon packaging and
the original Laravel Cloud pre-alpha staging assumptions are superseded by the
Cloud production baseline in [`docs/operations/deployment.md`](../operations/deployment.md)
and [`docs/deployment/laravel-cloud.md`](../deployment/laravel-cloud.md).

Do not use archived documents to infer currently enabled capabilities.
