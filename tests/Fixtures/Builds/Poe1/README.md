# PoE1 regression corpus

These files are original Lootwright test inputs shaped like PoB1 XML. They
cover the supported parser surface across melee, ranged attack, spell, minion,
totem, mine/trap, DoT, crit/non-crit, defence profiles, and content goals.
Their expected findings are intentionally limited to the reviewed PoE1 rule
registry; unimplemented mechanics remain explicit rather than inferred.
